# ExactDomain

A single-file browser app for deep exact-phrase web searching with one saved result per domain.

## Features

- Main exact phrase search
- Two additional text fields evaluated as OR
- Deep continuation searches
- One result per domain
- Saved search topics in browser storage
- US-focused searching and filtering
- CSV export with the direct page URL for every saved domain

## API key

The public repository intentionally does not contain a Serper API key. On the first search, the app asks for your key and stores it only in that browser's local storage.

Open `index.html` directly or publish this folder with static hosting.
